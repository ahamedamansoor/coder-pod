Favicon Generator Instructions

Method 1: Online Converter (Recommended)

  1. Go to: https://favicon.io/favicon-converter/
  2. Upload your logo.svg file from /public/logo.svg
  3. Download the favicon.ico file
  4. Replace /public/favicon.ico with the downloaded file

Method 2: RealFaviconGenerator

  1. Go to: https://realfavicongenerator.net/
  2. Upload your logo.svg file
  3. Configure your favicon settings
  4. Download the complete favicon package
  5. Extract and place files in /public/ folder
